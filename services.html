// services

What we do.

PR and web development, run by the same person — so the strategy and the build never fall out of sync.

PR & Sponsorship
Outreach strategy, sponsor decks, brand partnerships — running multiple prospects in parallel rather than one at a time.
Includes: sponsor targeting, outreach scripts, deck design, follow-up cadence
Web Development
Full-stack builds — event sites, checkout flows, live data-backed pages, admin dashboards.
Includes: Node.js/React builds, Paystack/Monnify checkout, Supabase-backed live data
Brand Strategy
Identity, positioning, and the digital presence that ties a brand's PR and product together.
Includes: visual identity direction, domain/site architecture, messaging
Event Systems
Ticketing, live counts, and the checkout mechanics that make an event site actually functional on the night.
Includes: tier-based pricing, real-time inventory, payment integration
Admin Dashboards
Custom admin panels so you can update your own content without touching code.
Includes: Supabase-backed CMS, image uploads, single-login auth
SEO & Discovery
Making sure the site people find is the one you built, not a stale link somewhere else.
Includes: Search Console setup, canonical tags, redirect strategy
Webmaster
Ongoing upkeep once a site is live — updates, uptime, and the boring-but-critical maintenance work.
Includes: hosting oversight, security patches, content updates
Domain Management
DNS, registrar migrations, subdomain routing — the infrastructure most agencies don't touch.
Includes: Cloudflare setup, wildcard subdomains, nameserver migration
